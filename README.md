# Delta Lake Demo

> **Project status:** Historical learning exercise. This repository is retained for reference and is not actively maintained.

This repository contains an exported Azure Data Factory example created while following a Delta Lake data engineering exercise.

## Contents

- `adf_data` contains the exported data factory resources used in the exercise.

## Source material

The exercise was based on *Data Engineering with Apache Spark, Delta Lake, and Lakehouse* from O'Reilly Learning. Access to the original course or book may require a subscription.

This repository contains my exercise output. It does not reproduce or replace the source publication, and it should not be treated as a current production architecture.
